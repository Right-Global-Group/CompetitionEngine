# Funding

> Review and manage funding applications submitted through the platform.

---

## Overview

The Funding page manages applications from organisations or individuals who have applied for funding through the platform's funding feature. Applications flow in from the public-facing funding application form and are reviewed and actioned here.

---

## Applications list

The applications list shows all submissions with filters for status, search by name, and a week-based date filter to view applications from a specific week.

| Column | Description |
|--------|-------------|
| **Name** | The applicant or organisation name |
| **Status** | Current application status |
| **Awarded** | Whether the funding has been awarded |
| **Submitted** | When the application was received |

---

## Filtering applications

| Filter | Options |
|--------|---------|
| **Search** | Filter by applicant name |
| **Status** | Pending, Approved, Rejected |
| **Week** | This week, last week, or further back |

---

## Application statuses

| Status | Meaning |
|--------|---------|
| **Pending** | Newly submitted, not yet reviewed |
| **Approved** | Application has been approved |
| **Rejected** | Application has been declined |

---

## Reviewing an application

Click any application to open its detail view. You can read the full application, update the status, add admin notes, and toggle the awarded flag.

### Updating status

Change the status to Approved or Rejected using the status selector. The change is saved immediately.

### Admin notes

Add internal notes to an application using the Notes field. Notes are visible only to admins and are not shown to the applicant.

### Awarded flag

Toggle the **Awarded** flag to indicate that the funding has actually been paid out, separate from the approval status. This is useful when approval and payment happen at different times.

---

## Bulk actions

Select multiple applications using the checkboxes and use the **Bulk Update Status** action to approve or reject them in one step.

---

## Pagination

Applications are paginated with 15 per page by default. Use the page controls at the bottom to navigate.
